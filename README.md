# SupplementaryInfoPackage-SEEmpathyTool
# MyEmpathiSEr: A Web Tool for Administering Empathy Scales in Software Engineering
# Authors: Hashini Gunatilake, John Grundy, Christina Burke-Broderick, Divyanjali Thirunavukkarasu, Devan Fedhi, Riya Vyas, Jeffrey Yan, Shekah Alayadhi, Trung Nguyen

This is the supplementary information package of the ICSE 2027 Tool Demo paper titled "MyEmpathiSEr: A Web Tool for Administering Empathy Scales in Software Engineering" authored by Hashini Gunatilake, John Grundy, Christina Burke-Broderick, Divyanjali Thirunavukkarasu, Devan Fedhi, Riya Vyas, Jeffrey Yan, Shekah Alayadhi, and Trung Nguyen.

This repository contains,
  - User Evaluation guide used in Iteration 1
  - User Evaluation guide used in Iteration 2
  - Admin Functionalities Testing guide and
  - Empathy Score Thresholds
